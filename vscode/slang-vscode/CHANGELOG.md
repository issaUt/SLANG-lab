# Changelog

## 0.1.0

- Initial SLANG language mode for VSCode.
- Added `.SL` and `.sl` file association.
- Added syntax highlighting for comments, strings, numbers, declarations, types, control keywords, operators, registers, system arrays, built-in functions, and function calls.
- Added preprocessor highlighting for `#INCLUDE`, `#CHAIN`, `#IF`, `#ELSE`, `#ENDIF`, `#MODULE`, `#ASM`, and `#END`.
- Added embedded Z80-style assembler highlighting for `#ASM ... #END` blocks.
- Added basic indentation and snippets.

# MZ-2500 IOCS グラフィックメモ

SLANG から MZ-2500 IOCS のグラフィック系 SVC を呼び出すための調査メモです。

## 前提

- このメモは `lib/iocs/MZ25IOCS_SVC.LIB` の試作実装に対応します。
- BASIC システム上での動作確認を前提にしています。
- 640x400 では、一部の IOCS が通常の SLANG ワーク領域に置いたパラメータブロックや文字列を読めない場合があります。

## 200ライン用と400ライン用

`PSET` と `SVMBL` は、200ラインと400ラインで呼び出し方法を分けています。

- `IOCS_PSET_RAW`
  - 640x200向け。
  - 通常の SLANG ローカルバッファを `HL` に渡します。

- `IOCS_PSET_RAW400`
  - 640x400向け。
  - BASIC と同じ低位ワーク領域 `$0CC0` にパラメータを置いて呼び出します。

- `IOCS_SVMBL`
  - 640x200向け。
  - 通常の SLANG ローカルバッファと文字列ポインタを使います。

- `IOCS_SVMBL400`
  - 640x400向け。
  - `$0CC0` にパラメータ、`$0CD0` に文字列本体をコピーしてから呼び出します。

## 低位ワーク領域を使う理由

BASIC の `PSET` / `SYMBOL` 相当処理も、内部では `$0CC0` 付近にパラメータを作ってから IOCS を呼んでいることを確認しました。

SLANG から通常のローカル配列を `HL` に渡すだけだと、640x400 の `PSET` / `SVMBL` では描画されませんでした。一方、BASIC と同じように低位ワーク領域へパラメータを置くと描画できます。

このため、400ライン用関数では `$0CC0` / `$0CD0` を一時ワークとして使います。長い文字列や同時利用する処理では、この範囲の上書きに注意してください。

## スクロール

`IOCS_HROLL(BYTE MODE, WORD Y)` を追加しています。

- `MODE = 0`
  - `Y` を指定してハードウェアスクロールします。

- `MODE != 0`
  - Cy=1 で `SVC_HROLL` を呼び、スクロール状態を初期化します。

`examples/iocs/GTEST.SL` では、パレット変更表示中に ESC を押したあと、`IOCS_HROLL` を使ったスクロールを確認できます。
